FLN Learning Program — 120 games

ShippedTeam leadAndroidiOSWebGL

The work I lead at Jnyanam Innovative Learning: a 120-title educational game program for young children, delivered set by set and shipping on phone, tablet and web.

Rather than build 120 one-off games, we built one configurable mechanic system — CombinedGameMechanicManager, with a custom Unity editor — covering button-clicker, match-the-pairs and drag-and-drop mechanics, alongside shared managers for player data, scoring and leaderboards. A new game is now mostly configuration rather than new code. Each set spans twelve learning categories, from sensory and numeracy through to daily-life skills.
